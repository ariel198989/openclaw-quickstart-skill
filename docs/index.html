What you actually get

A real agent running on real hardware that you control. Not a demo. Not a wrapper. Yours.

⚡

Always-on agent

Runs 24/7 on your Hostinger VPS. Checks email, books flights, manages calendar, watches prices — while you sleep.

💬

Chat from anywhere

Connected to Telegram. Add WhatsApp, Discord, Gmail later. Talk to your agent like a person.

🔒

Locked-down

Tailscale private network, UFW firewall, Fail2ban, allowlist to just your number. All optional, all automated.

🧠

Persistent memory

The agent writes to memory/ on the VPS. Remembers preferences, learns over time. Yours to inspect.

🔑

Sign in with ChatGPT

One OAuth click. Uses your ChatGPT Plus / Pro subscription — flat rate, no per-token billing, no API key to manage. (Claude.ai login + manual API keys also supported.)

🛠️

Extensible

OpenClaw runs MCPs, plugins, custom skills. Ask the agent to install whatever it needs — it can.

13 scenes. ~15 minutes.

1m

2m

1m

Creates a 64-char URL-safe random token, fills the form, shows you to save it.

10s
06
Sign in with ChatGPT wizard + you recommended

One OAuth click. Uses your ChatGPT Plus ($20) or Pro ($200) subscription — flat rate, no API key, no token billing. (Manual API key fallback also supported.)

1m

Wait for Deploy wizard

Polls Hostinger Docker Manager every 30s until container status hits Running.

1–3m
08

10s

2m

Pastes the bot token to OpenClaw, grabs the pairing code, sends it to your bot.

1m

30s

Install in one line

Free. No accounts to create here. The installer just drops the skill into your local Claude Code.

  1. 1

    Have Claude Code installed?

    If not, grab it free from claude.com/claude-code.

  2. 2

    Run the installer

    Picks up Playwright MCP if missing.

    PS> iwr https://raw.githubusercontent.com/ariel198989/openclaw-quickstart-skill/main/install.ps1 | iex
    $ curl -fsSL https://raw.githubusercontent.com/ariel198989/openclaw-quickstart-skill/main/install.sh | bash
  3. 3

    Restart Claude Code, then type:

    /openclaw-quickstart

מה זה עושה?

Wizard ב-Claude Code שפותח את הדפדפן שלך, מוביל אותך דרך הזמנת VPS ב-Hostinger, יוצר מפתח Anthropic, מקים בוט טלגרם, ומחבר את כולם — בלי שתצטרך לפתוח טאב בעצמך.

אתה מטפל רק ב-4 דברים: סיסמת חשבון, תשלום, אימות SMS אם נדרש, והודעה ראשונה לבוט. Wizard עושה את כל השאר.
