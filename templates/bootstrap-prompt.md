# Bootstrap — הודעה ראשונה לסוכן

הדבק כצ'אט הראשון אחרי שה-UI עולה:

---

```
היי. זה התקנה ראשונה. בבקשה:

1. הצג את עצמך — מה אתה, מה היכולות שלך, איזה כלים יש לך.
2. בדוק שכל המפתחות שהוגדרו (Anthropic / OpenAI / Gemini / Grok) עובדים — קרא test לכל אחד.
3. בדוק את הגישה לאינטרנט (web search, fetch).
4. צור קובץ `memory/bootstrap-<DATE>.md` שמכיל את הסטטוס + מה שתלמד עליי במהלך השיחה.
5. אחרי בדיקת חיים — שאל אותי שאלה אחת כדי שתבין מי אני ומה אני רוצה ממך.
```

---

## למה זה הצעד הראשון

- מאמת שהמפתחות נקלטו (יותר מהיר מלחפש בלוגים)
- יוצר memory file ראשון — בסיס לזיכרון ארוך טווח
- מציב את הסוכן במצב "להקשיב למשתמש" מההתחלה
